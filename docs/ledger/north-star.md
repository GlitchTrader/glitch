# Glitch North Star

## Product doctrine

```text
Trust before intelligence.
Native NinjaTrader state before cached or inferred state.
Hermes decides; Glitch validates, executes, protects, replicates, reconciles, and journals.
The User and Hermes own cognition. Glitch is deterministic equipment: it equips,
translates, executes, and reports; it does not police, micromanage, suppress,
counter-trade, or replace supported User/Hermes intent.
```

## Current product lines

- Standard v0.0.2.5 is the official stable default download.
- Experimental AI v0.0.2.6, paired with Hermes profile v0.0.2.17, is the current temporary main-product promotion at `e35f93a`. It remains separate and carries no profitability, unattended-operation, PA, or live-readiness claim.
- `main` owns the explicit release catalog. A ZIP is not a release until the catalog and checksum register it.

## Invariants

- Native NinjaTrader account, position, order, execution, and PnL truth outranks local state.
- One producer-neutral runtime copies each master execution delta at the configured ratio, owns follower-native OCO protection and close propagation, and preserves manual follower changes without blocking later copies. Startup restore is observation-only; explicit enable, add, ratio/master edit, and Sync gestures each authorize their documented one-time alignment.
- Hermes owns thesis, direction, master quantity, geometry, timing, scaling, management, and self-review.
- The User is authoritative for direct commands and visible configuration. User
  and Hermes mistakes remain attributable to their cognition; Glitch must not
  induce or amplify them through defective facts, math, normalization,
  provenance, receipts, duplicate mutation, hidden policy, or substituted
  cognition.
- Inferred policy does not override Hermes intent or an already accepted native master execution.
- A structurally or natively non-executable command is reported with the exact
  fact or native result. Glitch preserves the intent and never substitutes an
  unrelated trade.
- Glitch may report a command as structurally or natively non-executable only
  when it cannot faithfully form or prove that exact requested mutation: invalid
  contract shape, unsupported native identity/action, duplicate/conflicting
  mutation ownership, unavailable required native fact, or an explicit
  human-enabled control. This is a factual equipment result, not a cognitive
  veto. Prop-firm capacity, liquidation buffers, sessions, and time windows
  remain packet evidence unless a visible default-off Settings action was
  explicitly enabled by the User.
- Code never chooses a strategy, quantity schedule, stop formula, risk percentage, target formula, quota, grid, or martingale behavior.
- Decisions, receipts, outcomes, journals, episodes, memory, and supervisory review remain attributable through stable IDs.
- Codex builds and verifies code; it is not a runtime trader.

Tests and compiles prove software shape, not profitability or account authorization. Historical plans remain provenance and never override current source, `ledger.json` on `main`, the release catalog, or current operator direction.
